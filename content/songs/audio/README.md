Built-in backing tracks live here.

Use canonical song-id filenames when possible:

- `stand_by_me.mp3`
- `wonderful_tonight.mp3`
- `all_of_me.wav`

SparkSuite will look for these extensions in order:

- `.mp3`
- `.wav`
- `.ogg`
- `.m4a`

If a file exists here for a song id, the performance screen will prefer it as the built-in local backing track.

Imported song audio and stems still override these files on a per-song basis.
