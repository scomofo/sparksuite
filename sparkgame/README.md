SparkGame Asset Archive

This folder is a visual source archive from the older SparkGame highway prototype.

What is here:
- `assets/highway`: guitar and piano highway backgrounds / lane concepts
- `assets/gems`: gem / bar art experiments
- `assets/vfx`: hit spark, combo flame, strike-line effects
- `assets/ui`: genre icon experiments

What is not here:
- live gameplay code
- chart parsing
- timing / lane logic
- current runtime integration

Current live highway code lives in:
- `js/spark-highway.js`

This archive was deduplicated on 2026-04-14 so only one asset tree remains.
